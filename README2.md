# Oasis Infobyte Web Development Internship - Task 2
## Personal Portfolio Website - Dhanashri Vikas Chandane

A modern developer portfolio website engineered with a cyber-dark aesthetic, interactive animations, skills breakdown, featured projects, printable/downloadable resume, and client-side validated contact form.

### 👤 Profile Details
- **Developer**: Dhanashri Vikas Chandane
- **Role**: Full Stack Web Developer & Frontend Specialist
- **Specialization**: React.js, Node.js, JavaScript (ES6+), Modern UI/UX
- **Internship**: Oasis Infobyte Web Development and Designing Internship (OIBSIP)
- **Task**: Task 2 - Personal Portfolio

---

### ✨ Key Features

1. **Cyber-Dark Theme with Glowing Accents**:
   - Deep obsidian background paired with electric violet and cyber cyan neon gradients.
   - Animated glowing avatar card with rotating gradient aura and floating experience pills.

2. **Interactive Typewriter Hero**:
   - Smooth loop typing effect dynamically cycling through roles:
     * *Full Stack Web Developer*
     * *Frontend Specialist*
     * *React & Node.js Enthusiast*
     * *Creative UI/UX Designer*
     * *OIBSIP Web Dev Intern*
   - Status indicator (*"Available for Opportunities"* with glowing pulse animation).

3. **About & Background**:
   - Narrative background, career objectives, and key personal metrics.
   - 4-point architecture strengths (Frontend, Backend & APIs, UI/UX, Speed & Optimization).

4. **Categorized Skills Matrix**:
   - Dynamic tab filtering: **All Skills**, **Frontend**, **Backend & DB**, and **Tools & DevOps**.
   - Animated progress bars triggered upon scrolling into the viewport.

5. **Featured Projects Showcase**:
   - 6 project cards including real links to OIBSIP Task 1 (Landing Page) and Task 3 (Temperature Converter).
   - Tech stack tags, project descriptions, and interactive demo/code links.

6. **Interactive Timeline (Experience & Education)**:
   - Milestone tracking for Oasis Infobyte Internship and Computer Engineering degree.

7. **Printable & Downloadable Resume**:
   - Clean, ATS-friendly curriculum vitae preview.
   - Dedicated print stylesheet (`@media print`) and instant "Download CV (PDF)" trigger.

8. **Contact Form & Social Connectivity**:
   - Comprehensive validation (name, email regex, message length).
   - Dynamic button spinner and animated toast notification upon sending.
